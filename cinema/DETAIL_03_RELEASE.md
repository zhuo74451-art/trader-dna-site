# Trader DNA / Detail 03

## Scope
This is a presentation release of the existing cinematic preview. It is not an event-production cutover, an assessment revision, a backend rollout, or a new identity system.
Canonical assessment owner: `82trade-team/trader-dna`. Public preview publisher: `zhuo74451-art/trader-dna-site`.

## Changes
- Open-edge answer folios replace heavy rectangular boxes. Equal visual weight for both choices; selected, hover, focus, keyboard and reduced-motion states remain distinct.
- Three neutral progress chapters and an answer-backed 18-cell decision receipt replace redundant progress strips. No inferred traits are revealed during answering.
- Sage-gray atmospheric quiz surface; no opaque Q12 black curtain and no final-reveal silence timer.
- The identity backboard, foreground rail, inspect control, sticky decision scenes and physical share object remain intact.
- Paul Tudor Jones line drawing and Ed Seykota illustration are replaced by source-backed photographs. Six existing thumbnail-derived portraits now use native originals. The original dimensions and qualifications are recorded in the portrait manifest.
- Historical painting/sculpture media are explicitly labeled. Existing editorial sources without a reuse grant are not represented as commercially cleared. Resizing is never claimed to restore real detail.
- Typography, spacing, per-person crop, archive edges, source attribution, mobile layouts, focus restoration and optional A/B key selection were refined.

## Cache update
The new `cinema-detail-03.html` entry and content-addressed CSS/JavaScript avoid old cache keys. The existing cinema aliases serve the same release. Preview resources are network-first with `cache: no-store`; successful responses are retained only for exact-key network-failure fallback. Cache rotation deletes only this application's old cache namespace. Saved answers are not deleted. A version-message handshake distinguishes cache cleanup from actual controller activation.

## Verification
See the attached machine-readable acceptance and cache-upgrade reports for actual results. The legacy-worker test first reproduces cache-first + ignoreSearch staleness, then follows the new-entry update path without clearing storage or caches.
The browser suite covers real 18- and 54-answer routes, result persistence, no curtain creation, preserved layers/sticky scenes, 32 source-backed archive entries, 1080x1350 and 1080x1920 PNG downloads, 320/390/768/1440 layouts, keyboard and reduced-motion operation.
Automated Chromium and responsive emulation are not physical iPhone Safari / Android acceptance. Original assessment/data/persistence files are unchanged.
