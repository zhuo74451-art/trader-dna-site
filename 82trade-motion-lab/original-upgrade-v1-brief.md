# 82Trade Original Site Upgrade V1 — Visual + Experience Brief

## 1. Purpose
- Product/page: 82Trade homepage conversion landing page
- Primary user: first-time visitor, viewer from YouTube/social, prospective community member
- Primary action: join Discord / enter learning content
- First 3 seconds: "This is active, modern, trading-native, and there are real people/products here."
- Remember tomorrow: 82Trade = market judgement + learning + community, not a corporate brochure.

## 2. Existing truth
- Keep: black + cyan identity, 82TRADE wordmark, community members, current learning propositions, YouTube/Discord/LINE/OKX/Instagram links.
- Fix: brand-film pacing, excessive empty space, weak conversion cadence, low interaction density, weak hover feedback.
- Never break: real outbound links, current information truth, mobile readability, reduced-motion.
- Strong assets: member avatars, course thumbnails, 82Trade logo/wordmark, current copy.
- Missing: later product screenshots for Academy / Trader DNA / AI modules.

## 3. Art direction
Black conversion surface with thin structural lines, cyan micro-accent, real product/community media, and dense but disciplined interactive detail; it should feel like a trading product that has been designed carefully, not a keynote presentation.

- Composition: Kaiyn-style vertical conversion flow; content always leads to a proof point or action.
- Typography: direct, large but not billboard-only; more product landing than brand campaign.
- Image treatment: real thumbnails / community media inside product-like frames.
- Surface: near-black layers, 1px borders, subtle inner light, no generic glass everywhere.
- Contrast/density: denser than V56, still breathable.
- Motion: quick, tactile, inertial, 150–350ms. User input wins.

## 4. Reference assignment
- 82trade.com -> content truth, links, brand assets, three core learning propositions.
- Kaiyn -> conversion sequence, interaction density, marquee behavior, card push-up CTA, dark structural background.
- Coinbase -> product-card response, restrained hover depth, button feedback.
- Apple -> easing quality, transform discipline, no cheap bounce.

## 5. Scene map
| Scene | Task | Class | Intensity | Gap | Signature |
| --- | --- | --- | --- | --- | --- |
| Hero | understand + join | Story/Trust | M1 | Response/Identity | yes: community fan |
| Proof rail | establish legitimacy | Trust | M0 | Continuity | no |
| Learning cards | choose entry point | Utility/Story | M0 | Response | secondary |
| Conversion CTA | join / contact | Trust | M0 | Response | no |

## 6. Signature Moment
- Trigger: hover/focus on the community member group.
- Control: pointer/focus.
- Start: overlapped faces.
- Transform: faces fan outward; focused face rises/scales; group copy brightens.
- Payoff: social proof becomes tactile without becoming spectacle.
- Mobile: static overlapped faces + tap-safe CTA.
- Reduced motion: color/focus only.
- Why: community is a real conversion reason for 82Trade.

## 7. Static checkpoint
Hero must work as a still image; CTA + social proof visible without scrolling; product/media block must look useful even with motion paused.
